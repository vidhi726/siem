01. Problem Statement & Motivation

Modern Security Operations Centers (SOCs) are overwhelmed by attack velocity and fragmented tools.

⚠️ Excessive Ingestion & Detection Delays

Traditional SIEMs rely on batch searches running every 3 to 15 minutes, allowing cyber adversaries to establish persistence and move laterally before detection.

⚡ Severe Alert Fatigue

Analysts are inundated by hundreds of unranked, context-deficient alerts lacking MITRE ATT&CK taxonomy or external reputation scoring.

🛑 Passive Architecture (Zero Active Defense)

Legacy SIEM platforms merely log events. Mitigating an attack requires manual intervention or expensive separate SOAR tools, inflating MTTR.

💰 Prohibitive Data Volume Costs

Commercial licensing models charge $1,200–$2,000 per GB/day, forcing organizations to discard security logs and create dangerous visibility gaps.

02. Project Objectives & Scope

  • Sub-Second Stream Analytics: Decouple ingestion from correlation using Redis Streams to achieve >25,000 events/second throughput.
  • Composite Detection Paradigms: Support sliding-window Threshold, Sequence, and Aggregation rules.
  • Unified 1-Click SOAR: Direct execution of perimeter firewall drops, host network quarantine, and IAM token revocation.
  • MITRE ATT&CK® Enterprise Navigator: Real-time interactive matrix mapping coverage across all 14 tactics.
  • Cryptographic Non-Repudiation: HMAC-SHA256 digital seals ensuring evidence integrity for forensic audit reports.
  • Analyst Tactical Cockpit: React 19 UI with Web Audio alarm chimes, visualizer pill, and local timezone time navigation.

04. Multi-Paradigm Correlation Engine

1. Threshold Rules

Flags volumetric spikes exceeding frequency thresholds within sliding windows.

Example: >5 failed login attempts from a single source IP in 60s.

2. Sequence Rules

Identifies multi-stage attack chains executed in strict temporal order.

Example: Recon Port Scan followed by Auth Failure and Privilege Escalation.

3. Aggregation Rules

Detects statistical anomalies across dynamic group-by keys.

Example: Single IP attempting logins across >10 distinct usernames (Password Spraying).

4. Sigma Rule Interoperability

Bi-directional YAML translation allowing direct import/export of global Sigma community rules.

05. Active SOAR Defense (1-Click & Policy Actions)

Transforms the SIEM from a passive observer into an active response platform:

🔥 Perimeter Firewall IP Drop

Pushes dynamic blocklist rules to perimeter firewalls or iptables, terminating inbound C2 connections instantly.

1-Click Containment

🔒 Host Network Isolation

08. Cryptographic Forensics & Chain-of-Custody

Ensuring tamper-evident non-repudiation for legal and regulatory compliance:

🔐 HMAC-SHA256 Digital Sealing

Every generated alert is bound to a cryptographic HMAC signature combining: Alert ID + Rule ID + Timestamp + Severity + Matched Event IDs.

If an attacker modifies database records post-compromise, the signature check fails immediately.

📄 1-Click Forensic Case Dossier

Exports complete incident Markdown reports containing verified digital signatures, matched log telemetry, and containment execution audits ready for court presentation.

09. Real-World Adversary Simulation Engine

Four pre-configured playbooks to validate detection rules and train analysts:

1. SSH / RDP Brute Force

Generates rapid failed authentication bursts, triggering Credential Access alerts (T1110).

2. DNS Tunneling Exfiltration

Queries high-entropy pseudo-random subdomains to simulate covert C2 exfiltration (T1071.004).

3. Phishing Credential Theft

Emulates user credential submission to suspicious external landing pages (T1566).

4. Linux Sudo Privilege Escalation

Simulates unauthorized privilege escalation via sudoers manipulation (T1068).
